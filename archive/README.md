# Archive

This directory preserves superseded project material so the repository can stay readable without erasing useful history.

- [`copilot-era/`](copilot-era/README.md) contains reports, duplicate launchers, demo runtime code, and retired deployment or monorepo configuration found during the 2026-07-29 cleanup.
- Archived files keep their original content whenever possible.
- Nothing under `archive/` is imported, tested, packaged, or deployed by the maintained application.
- Consult the current [README](../README.md) and [documentation index](../docs/INDEX.md) before reusing anything here.

Restoration should be intentional: copy the relevant idea into an active module, update its assumptions, add tests, and document why it is supported again.
