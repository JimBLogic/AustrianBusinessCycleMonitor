## Austrian Economics Resources

### Core Concepts
- **Business Cycle Theory**: How credit expansion creates artificial booms and inevitable busts
- **Three Pillars Framework**: Credit, Market Signals, and Capital Structure analysis
- **Praxeological Method**: Logical deduction from action axioms

### Key Thinkers
- **Ludwig von Mises**: Human Action, business cycle theory
- **Friedrich Hayek**: Knowledge problem, spontaneous order
- **Murray Rothbard**: Central banking critique, Austrian methodology

### Modern Applications
- **Real-time Monitoring**: FRED API economic data integration
- **Multi-asset Analysis**: Bitcoin, precious metals, market indices
- **Risk Assessment**: Quantitative Austrian indicators

## System Architecture

The monitoring system implements Austrian theory through:

1. **Credit Expansion Tracking**: Federal funds rate, M2 money supply
2. **Market Signal Analysis**: Interest rate spreads, asset prices
3. **Capital Structure Monitoring**: Investment ratios, economic complexity
